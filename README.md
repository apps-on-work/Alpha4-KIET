# Alpha4-KIET
It is a website that gives you collective info of your campus, what's happening around giving a new  guide to freshers


# Future Plans
1. Integration of NEXT.js for login to make it more secure and user-friendly
2. Google Firebase for Backend database
3. A map through for campus via cloud API of google maps
4. A guide 101 with notes PDF
5. Club management and events display for general and user specific
6. A random chat feature to spice engagement tho we are not putting much bets on this one
7. Gemini AI integration for the entire website

## ⚡ Getting Started

Follow these steps to set up the project locally on your machine.

### Prerequisites

Make sure you have the following installed:
* Git
* [Node.js / Python / Flutter SDK depending on project]

### Installation

1.  **Clone the Repo**
    ```sh
    git clone [https://github.com/apps-on-work/Alpha4-KIET.git](https://github.com/apps-on-work/Alpha4-KIET.git)
    ```
2.  **Navigate to the directory**
    ```sh
    cd Alpha4-KIET
    ```
3.  **Install Dependencies**
    ```sh
    npm install
    # OR if using Python
    pip install -r requirements.txt
    ```
4.  **Configure Environment Variables**
    Create a `.env` file in the root directory and add your API keys:
    ```js
    API_KEY=ENTER_YOUR_API
    DB_URL=ENTER_YOUR_DB_URL
    ```
5.  **Run the Project**
    ```sh
    npm start
    # OR
    python app.py
    ```
